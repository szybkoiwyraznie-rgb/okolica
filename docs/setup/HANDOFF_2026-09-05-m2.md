## 2. Jak uruchomić i jak sprawdzić

```bash
cd okolica
npm run brama          # 241 testów (node --test) + sprawdzenie szablonu promptu
npm test               # same testy
npm run serwer         # python3 -m http.server 8000 --bind 0.0.0.0
```

Podgląd: live preview Areny (albo `http://localhost:8000`), a do testów bez GPS
`?tryb=test` — odsłania ręczne współrzędne. W sandboxie agenta działa serwer na
porcie **8000** (stary) i **8080** (uruchomiony w tej sesji jako „Podgląd mapy").

**Weryfikacja mapy jest obowiązkiem właściciela** — procedura krok po kroku:
`docs/WORKFLOW.md` §4.1 (kafelki, drag, pinch, przyciski ±/◎, pasek skali,
atrybucja, zmiana podkładu, obrót telefonu). Agent nie ma przeglądarki ani
sieci do `tile.openstreetmap.org` (LESSONS L3), więc nie może tego sprawdzić.

## 3. Co kod umie, a czego nie umie

**Umie:** pięć ekranów (setup → pozycja → stacje → prompt → paczka) z walidacją
konfiguracji (kody K01–K20), prompt PYT v1.0, walidacja paczki (E01–E20) z
„poprawką dla modelu", ukrywanie paczki (`TO-paczka/2`, obfuskacja bez klucza),
geolokalizacja przez osłonę `watchPozycja()` (kody P01–P09, pauza w tle,
wznowienie), tryb testowy z ręcznymi współrzędnymi i symulacją trasy,
**model rozgrywki** jako czyste funkcje (kolejka graczy, odcinki i czasy, kara
za ręczne zgłoszenie, punktacja względem mediany tempa, dziennik,
podsumowanie — kody G01–G13) oraz **mapa** (podkład rastrowy bez klucza API,
drag/pinch/kółko, przyciski ±/◎, marker z kołem dokładności, okrąg promienia,
numerowane pinezki stacji, pasek skali, atrybucja).

**Nie umie (świadomie, zgodnie z `ROADMAP`):** **ekranu gry** — model rozgrywki
jest policzony i przetestowany, ale nieklikalny (M6); stacji na sieci dróg,
placów i szlaków z Overpass (M4 — dziś pierścień z `stacje.js`); podglądu
„tylko dla organizatora" z ręczną edycją paczki i odwrotnej geokodacji nazwy
miejsca (M5); ekranu „dane i prywatność" (M3); trwałego zapisu stanu gry
(`app/trwalosc.js` — dziś stan żyje w pamięci, a `wczytajStan()` ↔
`JSON.stringify(stan)` to przetestowana para gotowa do zapisu; w `ROADMAP`
należy do **M6**, bo jego kryterium mówi o wznowieniu po zamknięciu
przeglądarki); podsumowania graficznego i eksportu wyniku (M7); publikacji na
GitHub Pages, manifestu i CI (M8); repozytorium paczek (M9); service workera
i offline (M10).

**Uwaga na fakty, które zmieniły znaczenie:** kara za ręczne zgłoszenie dojścia
jest **czasowa** (`karaRecznaS`, domyślnie 60 s doliczane do `czasS`), nie
punktowa (ADR 0004 pkt 5 + ADR 0014 pkt 6). Stan gry `rozgrywka/1` **nie niesie
treści pytań** — tylko `{stacja, pytanieId}` (ADR 0007 pkt 6).

## 5. Fakty operacyjne, które trzeba znać

- **Stan pusha:** w środku sesji uwierzytelnienie GitHub odmawiało
  (`Bad credentials`), więc commity od `cfa9fdb` wzwyż czekały lokalnie. Po
  odświeżeniu tokena przez właściciela **wszystko jest wypchnięte** na
  `arena/01a07282-okolica`, a opis **i tytuł** PR #2 zaktualizowane przez
  GraphQL (`updatePullRequest` — `gh pr edit --body-file` w tym środowisku
  zawodzi; działająca forma to `gh api graphql --input -` z pełnym JSON-em
  `{query, variables}` w stdin, bo flagi `-f` nie trafiają do `variables`).
  Uwaga: `gh api user` potrafi odpowiedzieć `403 Resource not accessible by
  integration` nawet przy działającym tokenie — to nie jest wyznacznik
  sprawności; miarodajne są `git push` i `gh pr view`.
- **Opis PR #2 aktualizuj przez GraphQL** (`updatePullRequest`), bo
  `gh pr edit --body-file` w tym środowisku zawodzi; szkic: `/home/user/pr-body.md`
  (poza repo, **nieaktualny** — opisuje stan sprzed M2).
- **Weryfikacja commitów przed pushem**: `git worktree add /tmp/wt <sha>` i tam
  `npm test` — liczby testów w komunikacie commitu muszą pochodzić z worktree,
  nie z pamięci.
- **`node --test` traktuje każdy `.js` w `test/` jak plik testowy**, więc
  `test/helpers/dom.js` liczy się jako jeden trywialny test i nie może mieć
  asercji ani skutków ubocznych na poziomie modułu.
- **Edycja plików skryptem**: kopiuj fragment z pliku, nie przepisuj (LESSONS
  L12); przy powtarzających się liniach szukaj od wskazanego miejsca
  (`idx(fragment, start)`), a zapisuj po każdej łatce — najpewniejsze są
  wstawienia po numerze linii albo `edit_file`.
- **Atrapa DOM**: kilka importów `app.js` dzieli globale, więc testy
  reinstalujące atrapę idą **na końcu** pliku i importują moduł z unikalnym
  query (`?mapa=<los>`); `pobierz(id)` tworzy element na żądanie, więc
  `querySelector` zwraca `null` — kod, który na tym polega, w teście nie
  działa (i w przeglądarce przy wolnym renderowaniu też).
- **Cache-busting**: wszystkie `?v=` w `index.html` i w importach `app/app.js`
  muszą mieć tę samą wersję (pilnuje `test/kontrakt.test.js`); teraz `?v=m2-1`.

## 7. Co się zmieniło w regułach pracy (do zapamiętania)

- **LESSONS L13** — schowany panel ma rozmiar 0: komponent mierzony z DOM musi
  mieć jawną ścieżkę `pusty`, kasować pamięć stanu (sygnaturę/cache) i być
  odświeżany przy pokazaniu ekranu oraz przy `resize`.
- **LESSONS L14** — rejestracja nasłuchów ma jedno miejsce; test asertuje liczbę
  nasłuchów po utworzeniu **i** po zniszczeniu, a potem wysyła zdarzenie.
- **LESSONS L15** — przy kilku modelach jednostek test przelicza w obie strony
  i porównuje z niezależnym źródłem (`r_swiat × skala === r_piksele ===
  metry / mpp`); „dodatnie i skończone" przepuści zamianę mnożenia na dzielenie.
- **Atrapa DOM umie SVG**: `createElementNS`, `replaceChildren`, `removeChild`,
  `getBoundingClientRect` + `ustawProstokat()`, no-op `setPointerCapture`,
  działający `removeEventListener`.
- **Kontrakt pilnuje mapy**: kompletność szkieletów paneli w `index.html`,
  dostępność (`role="img"`, `aria-label`, `type="button"`), zakaz domyślnego
  `display: none` dla atrybucji, `touch-action: none` na panelu, brak
  `fetch`/geolokalizacji/`alert`/`node:` w `mapa.js`, szablony URL kafelków
  identyczne z `ASSETS` §1 (po ujednoliceniu `{s}` ↔ `{a,b,c}`).
- **Przejście między ekranami waliduje stan**: `stacjeProste` odmawia przy
  niedodatnim promieniu, więc ekran, który ją woła, najpierw sprawdza
  `STAN.konfig` i odmawia jawnie z kodami K — wyjątek w nasłuchu to biały ekran.
