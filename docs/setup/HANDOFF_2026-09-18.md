## L59 — ostrzeżenie dla następnej sesji (sandbox)

Sandbox **dwukrotnie tego dnia resetował lokalny `.git`** na świeży clone
(`44c80e1`), podczas gdy tip odległy był `c19344e`; drugi reset zastał
niezacommitowaną pracę. Diagnoza: `git rev-parse HEAD` + `git reflog` +
`git ls-remote origin <branch>`. Odzyskiwanie: overlap-check (`git diff
--name-only <baza> FETCH_HEAD`), snapshot `tar --exclude=.git -cf /tmp/… .`,
usunięcie untrackedów śledzonych w FETCH_HEAD, `git reset --hard FETCH_HEAD`,
cherry-pick własnych commitów, odtworzenie plików ze snapshotu. **Odległa
gałąź = trwały magazyn: push po każdym zielonym commicie.**
