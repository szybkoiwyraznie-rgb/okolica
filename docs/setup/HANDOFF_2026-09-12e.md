## Pułapki potwierdzone w tej sesji

- **Skrypt edycyjny z pojedynczym zapisem na końcu**: `AssertionError`
  w połowie = plik bez zmian (dobre!), ale trzeba to potwierdzić grepem/diffem —
  i nie używać `skrypt && npm test` jako dowodu, bo test przejdzie na starym
  kodzie (LESSONS L53).
- **Kontrakt LESSONS wymaga etykiet `**Objaw:**`/`**Przyczyna:**`/`**Reguła:**`
  dokładnie w tej postaci** — dopisek w nawiasie wewnątrz etykiety
  (`**Objaw (…):**`) czerwieni bramę.
- **Kontrakt intro pinuje brzmienie i zawinięcie wiersza w HTML** — po zmianie
  akapitu trzeba poprawić regex (`\s+` zamiast spacji) albo ułożyć HTML tak,
  żeby pinowana fraza była w jednym wierszu.
- **Walidator paczek odrzuca paczkę bez widocznego powodu w `#bledy-paczka`** —
  liczba usterek jest w `#wynik-naglowek`, treści w `#wynik-usterki`
  (LESSONS L54).
- **`gh pr edit` na tym repo pada** (GraphQL Projects classic) — działa
  `gh api -X PATCH repos/<owner>/<repo>/pulls/<n> -f title=… -F body=@plik`.
