## Pułapki potwierdzone w tej sesji

- **Funkcje niesąsiadujące z usuwanym blokiem**: `przelaczSetup` siedział
  W ŚRODKU sekcji rankingów i wyleciał razem z nią — 16 testów UI padło na
  `ReferenceError`, nie na asercji. Przy wycinaniu sekcji grep po nazwach
  z `git diff | grep '^-function'`.
- **`git add` a cache-bust** (LESSONS L29): podbicie `?v=` dotyka WSZYSTKICH
  modułów `app/*.js`; commit z częścią grafu nie jest samodzielnie zielony
  (kontrakt pilnuje jednej wersji).
- Testy UI multi potrzebują `?tryb=test&odstep=0` (LESSONS L21) i atrapy mostu;
  ścieżka „sieć drogowa dostępna" idzie przez **cache** (`kluczCacheSieci`
  + `upraszczajDaneDoCache(parsujOdpowiedz(fixture))`), bo egress HTTPS
  w sandboxie jest ograniczony do `api.github.com` i `registry.npmjs.org`.
- **Cache obcego dostawcy ≠ cache aplikacji** (LESSONS **L47**): zasoby
  adresowane treścią (kafel `z/x/y`) nie mogą mieć wersji w nazwie cache.
  Test, który tego pilnuje, symuluje dwa wdrożenia na **tym samym** magazynie
  (harness `new Function` w `test/sw.test.js` przyjmuje `kod` i `magazyny`).
  Warto pamiętać: nowy test zawsze sprawdź na starym kodzie — jeśli nie
  czerwienieje, nic nie dowodzi.
- **Numeracja LESSONS jest pilnowana kontraktem** (`test/kontrakt.test.js`,
  „LESSONS ma ciągłą numerację"). Przed dopisaniem lekcji `grep -c '^## L'` —
  w tej sesji notatka mówiła o 45, plik miał już 46, i dopisek wylądował jako
  drugie L46.
- **DOM weryfikujemy atrapą, nie czytaniem HTML** (`test/helpers/dom.js` →
  `zainstalujDom`). Uwaga: `/home/user/.narzedzia` (Chromium/zrzuty ekranu
  z wcześniejszych sesji) **w tym sandboxie nie istnieje** — nie planuj
  screenshotów. Opcje segmentów nie mają `dataset.klucz`: `renderujSegment`
  buduje `<label><input type=radio value=klucz><strong>`, więc wybór idzie po
  `i.value` + ręczne odpalenie handlerów `kontener.zdarzenia.change`.
