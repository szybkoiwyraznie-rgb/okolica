## Pułapki potwierdzone w tej sesji

- **`adresMostu` woli URL multi nad URL repo** (`most.js`). W testach multi
  indeks idzie na most gry — osobny URL repo byłby martwy (multi 7/17
  przed poprawką). Przy cytowaniu priorytetów czytać kod, nie domysły.
- **`czekajNa` w multi drukuje globalny `status`** (hint lobby), nie
  `zestawy-status` — myli przy diagnostyce paczek.
- **Refresh propozycji** odpala się tylko na ekranie pozycji w promieniu
  250 m (`app.js` L1236, bramka) — diagnostyka poza ekranem daje 0 fetchy.
- **Transport literalny, display podwaja backslashe;** przed parą z PL
  znakami zrzucać `unicode_escape`. Cudzysłowy w historii mieszane
  (`„x"` obok bloków z `”`) — nie ufać sed/repr.
- **`gh pr edit/view` padają** (GraphQL Projects classic deprecated) —
  opis PR tylko przez `gh api repos/.../pulls/N -X PATCH -F body=…`.
