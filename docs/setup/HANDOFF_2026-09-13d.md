## Decyzje, które następna sesja musi znać

1. **Kolejność powrotu do gry jest częścią kontraktu.** `dostarczZalegleZdarzeniaMulti`
   musi być wołane PRZED `pobierzGetMulti` — inaczej telefon zbuduje trasę ze
   stacją, którą most właśnie domknął. Pin: test end-to-end z celem „stacja 2 z 3".
2. **`app/sync.js` nie wie o `localStorage`.** Trwałość jest wstrzyknięta z
   `app/app.js` (`pamiecOcen()` + `KLUCZ_KOLEJKI_MULTI`). Nie przenoś zapisu do
   modułu synchronizacji — testy jednostkowe wstrzykują tablicę.
3. **Bezpieczeństwo ponowienia opiera się na moście.** Most odrzuca drugą
   odpowiedź tego gracza do tej stacji (`przyjmijZdarzenie`
   w `docs/setup/apps-script-repo-paczek.gs`), więc częściowe dostarczenie nie
   tworzy duplikatu. Gdyby ta reguła kiedyś zniknęła, utrwalona kolejka staje
   się niebezpieczna — ADR 0019 aneks 2026-09-13d mówi to wprost.
4. **Wstępne pobranie NIE zgłasza mostowi użycia paczki** (oceny i licznik
   „użyta w X grach" idą dopiero przy prawdziwym kliku, ADR 0028). Nie
   „poprawiaj" tego na `wyslijUzycieWTle` przy pobraniu w tle.
5. **Kontrast animacji jest mierzony, nie zgadywany**: 5,62:1 (jasny) i 8,25:1
   (ciemny) przy najniższej przezroczystości 0,7. Mieszanie kanałów sRGB, nie
   średnia z luminancji (`tools/audyt-kontrastu.mjs`: `kontrast()`,
   `hexNaRgb()` zwraca TABLICĘ `[r, g, b]`).
6. **Pin „dokładnie jedna powtórka" (zimny start mostu) liczy żądania indeksu**,
   bo wstępne pobieranie dokłada żądanie pliku paczki.

## Rzeczy otwarte

1. **Scalenie PR #20** (decyzja właściciela) — Pages poda `?v=m12-114`,
   a `WERSJA_SW` wymieni cache skorupy, więc telefony podciągną falę bez
   ręcznego czyszczenia.
2. **Deployment web app u właściciela** — wisi od PR #19 (`rezygnacja` domykająca
   grę, pula premii). Ta fala mostu NIE zmieniała.
3. **Powtórka testu terenowego dwóch telefonów** (WORKFLOW §4.4), teraz także ze
   scenariuszem utraty zasięgu: odpowiedź bez sieci → odświeżenie telefonu →
   status mówi o wysłaniu zaległych zdarzeń, a cel to NASTĘPNA stacja.
4. **Budżet: rezerwa 628 tok** — wystarczy na jedną lekcję albo mały aneks;
   następna duża fala dokumentowa zaczyna od `npm run budzet` i ma gotowy
   mechanizm podziału (archiwum treści historycznej ADR-a żyjącego).
