## Pułapki potwierdzone w tej sesji

- **Cudzysłowy w dokumentach są MIESZANE** (proste `„x"` obok typograficznych
  `„x”`) — kotwice do pythonowych poprawek brać z `repr()` fragmentu pliku, nie
  z `cat`/pamięci; inaczej `assert count == 1` pada i CAŁA partia poprawek się
  nie zapisuje (plik pisany jest na końcu).
- **Numeracja wierszy** do edycji blokami: brać z `grep -n` tego samego dnia —
  `sed -n 'X,Yp'` bez `-n` z kotwicą łatwo pomylić o jeden wiersz (README:119
  poprawiany dwa razy).
- **Strażnik fraz musi mieć zakresy:** historia (`PROJECT_HISTORY`, `LESSONS`,
  ADR-y, handoffy) cytuje martwe frazy celowo, a testy asertują ich brak —
  więc frazy skanujemy tylko po nośnikach żywych (lista w teście), za to
  cytowania ADR także po `test/*.js`.
- **Zielone testy nie widzą tekstu:** 734 testy nie złapały 17 miejsc dryfu, bo
  czytały zachowanie, nie komunikaty. Każda zmiana tekstu UI albo dokumentu
  potrzebuje pinu (kontrakt albo strażnik), inaczej wróci przy następnej fali.
- **`gh pr edit/view` padają** (GraphQL Projects classic deprecated) — opis PR
  tylko przez `gh api repos/…/pulls/N -X PATCH -F body=@plik`.
